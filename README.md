# akashic dreams
modern portfolio and it studio site. built with next.js, typescript, and tailwind.

## features
- simple black and white design
- dark mode by default (looks cool)
- nice animations
- works on mobile
- content is just files, no database needed

## tech stack
- next.js 16
- typescript
- tailwind css
- framer motion for animations

## how to run it

### install stuff
```bash
npm install
```

### run locally
```bash
npm run dev
```

open [http://localhost:3000](http://localhost:3000)

### build it
```bash
npm run build
npm start
```
