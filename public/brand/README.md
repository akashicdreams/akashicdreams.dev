# Logo Placement Instructions

This directory is where you should place your Akashic Dreams logo files.

## Required Logo Files

The website requires 4 logo variants to support both dark and light themes:

### Icon-Only Logos (for navigation)
- **logo-mark-dark.svg** - Icon for dark mode (white/light colored)
- **logo-mark-light.svg** - Icon for light mode (black/dark colored)

### Full Logos with Text (for other sections)
- **logo-type-dark.svg** - Full logo for dark mode (white/light colored)
- **logo-type-light.svg** - Full logo for light mode (black/dark colored)

## File Format

- **Preferred**: SVG format for sharp rendering at any size
- **Fallback**: PNG files with the same naming convention are also supported

## Size Recommendations

### Icon-Only Logos
- Square aspect ratio
- Recommended: 512x512px minimum for PNG
- SVG can be any size (vector format)

### Full Logos
- Recommended width: 1000px minimum for PNG
- Maintain your brand's aspect ratio
- SVG can be any size (vector format)

## Color Guidelines

Since the website uses a monochrome design:
- Dark mode logos should be white or very light colored
- Light mode logos should be black or very dark colored
- Avoid colorful gradients (use monochrome only)

## Testing

After placing your logos:
1. Run `npm run dev`
2. Check the navigation (uses icon-only logo)
3. Toggle between dark and light mode
4. Verify logos swap correctly based on theme
